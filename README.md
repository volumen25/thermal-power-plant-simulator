# Thermal Power Plant Simulator - Course Website

Fall 2026

## Setup Instructions

1. Install Quarto: https://quarto.org
2. Install uv: https://docs.astral.sh/uv/
3. Run:
   ```bash
   uv sync
   quarto preview
   ```

## Python Scripts

Located in `python_scripts/`. Run with:
```bash
uv run python python_scripts/rankine_cycle_basic.py
```
